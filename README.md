# 📈 Simple Linear Regression: Predicting Average Income in Canada

## 📌 Project Overview
This project implements a **Linear Regression model** to analyze and predict the **average income of citizens in Canada over the years**.  
The primary goal is to understand **how income trends evolve over time** and to apply fundamental machine learning concepts such as **model training, cost optimization, and prediction**.

The project focuses on **clarity, mathematical intuition, and practical implementation**, making it ideal for learning and demonstration purposes.

---

## 🎯 Objectives
- Analyze historical income trends in Canada
- Implement a Linear Regression model to capture the relationship between **year** and **average income**
- Predict future income values based on learned trends
- Visualize model performance and regression fit

---

## 🧠 Concepts Covered
- Linear Regression (Supervised Learning)
- Cost Function (Mean Squared Error)
- Gradient Descent Optimization
- Data Visualization
- Model Evaluation and Prediction

---
